## Lesson planning, without the clutter.

Great teaching takes preparation. The process around it should feel clear, organised, and easy to follow.

**Lessoner brings lesson planning and approval into one straightforward flow**, from the first draft to the final print-ready plan. No hunting through scattered documents to figure out what needs attention next.

## One simple flow, from draft to done

<div align="center">

**Create** &nbsp; → &nbsp; **Submit** &nbsp; → &nbsp; **Review** &nbsp; → &nbsp; **Refine** &nbsp; → &nbsp; **Finalise**

</div>

Every plan has a clear place in the process:

| Status | What it means |
| --- | --- |
| **Draft** | Still being prepared |
| **Pending approval** | Submitted for review |
| **Needs revision** | Ready for another pass |
| **Finalized** | Approved and ready for use |

## Thoughtfully organised. Ready for real school routines.

- **Structured planning** — bring learning objectives, teaching methods, activities, resources, assessment, homework, and remarks together in one plan.
- **A clearer review journey** — see whether a plan is a draft, awaiting approval, needs revision, or is finalised.
- **Print-ready output** — use an A4-friendly layout for lesson-plan documents and signatures.
- **Comfortable across screens** — use Lessoner on a phone, tablet, or desktop.
- **A shared school workflow** — bring teacher and principal tasks into one organised experience.
